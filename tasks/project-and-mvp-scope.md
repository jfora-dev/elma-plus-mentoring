# ELMA+ Conseil - Internal Management Application

## Project definition

### The client<br>

**ELMA+ Conseil** is a construction consultancy providing project management and advisory services to construction and building projects.

Areas of expertise: Project management, Client-side project support, Scheduling supervision and coordination, Construction cost management, Fire safety expertise, Accessibility audits for people with reduced mobility.

The firm sells **time and expertise**, not materials or construction works. Its revenue comes
from fee-based assignments (missions) attached to construction projects.

### The problem<br>

Today this activity is tracked across spreadsheets, email and accounting software.
Consequences:

- Processes are manual: time consuming and error prone
- No single view of a project's commercial, operational and financial status
- No reliable forecast of revenue for the coming months

### The project<br>

An **internal web, single, fast and reliable application** for running the consultancy and tracking its construction projects, allowing to centralize the data and automate the processes.

It covers six modules (in order of implementation):

Module 1 - Client management: prospects, clients, legal entities, contacts, addresses

Module 2 - Access management: Authorization, Authentication, Role-based access control

Module 3 - Finance: quotes, invoicing and payments

Module 4 - Operations/Delivery: the assignments and services actually carried out on projects

Module 5 - Planning: budgets, forecasts and financial visibility

Module 6 - User management: add new users with different roles and permissions, edit, delete users

## Scope of MVP

The MVP covers Module 1 and Module 2:

- Client management: prospects, clients, legal entities, contacts, addresses
- Access management: Authorization, Authentication, Role-based access control (only for the admin user)

Current problem<br>
This project is a greenfield project to start from scratch, with nothing existing already. the user of the application has nothing to start looking at and test.

Objective of the MVP<br>
The priority of the MVP is to have a functioning web application with one business feature (clients management) and access management / authentication.
With this MVP, the user will be able to access the application securely and test the clients management feature.
